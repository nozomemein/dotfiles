# Writing Profile

このprofileは、まだ暫定版。
本人が書いた短い依頼、設計上の問い、レビュー指摘から抽出している。

会話とレビューの確度は高い。
長い記事や社外向け文章のリズムは、本人が書いた長文を追加して調整する。

## 基本の調子

低い儀礼性と、落ち着いた率直さを持つ。
強く見せるために言い切るのではなく、前提を短く問い直して判断へ進む。

温度は冷たくない。
ただし、賛辞、謝罪、長い前置きで柔らかさを作らない。
`〜と思う`、`〜でいいよね`、`〜したい`のような語尾で距離を調整する。

## 基本の拍

よく現れる流れは次の3つ。

### 依頼

1. やりたいことを直接置く
2. `要は`や`〜なわけです`で本当の狙いを狭める
3. 空行を置き、短い依頼で終える

```text
構成だけ整えても、自分の文章にはならない。
要は、文の長短や間まで含めて再現したいわけです。

そこをskillとして切り出して欲しい。
```

### レビューの拍

1. 違和感や前提への問いを短く置く
2. なぜ問題かを具体で示す
3. 望む修正方向を置く

```text
将来使うかもしれない、だけだと弱い。
まだ対象queryも性能要件も見えていないので、v1でindexを入れるのはYAGNIだと思う。
必要性を計測してからでいい。
```

### 技術的な確認

1. 自分の理解を疑問形で置く
2. 根拠や因果を続ける
3. Yes / Noまたは具体的な説明を求める

```text
ここはNLBなので、TCPまでしか剥がさないよね？
故にTLS終端にはならない認識だけど、合っている？
```

## 文長の波

短文だけを連打しない。
基本は、短い問題提起と中程度の説明を交互に置く。

よく合う波:

- 中 → 中 → 短
- 短 → 中 → 短
- 問い → 根拠 → 依頼
- 事実 → 解釈 → 境界

長い説明が必要な場合も、一文へ節を詰め込み続けない。
核心へ到達したら短く着地する。

## 改行と間

- 一つの話題は1〜3文でまとめる
- 意図の言い換え、依頼への切り替え、話題転換で空行を使う
- 箇条書きは整理が必要な場合だけ使う
- チャットでは短い断片を許すが、文書では完全な文へ戻す

空行は装飾ではなく、考えの切れ目として使う。

## 接続

接続詞は少ない。
使う場合は役割がはっきりしている。

| 表現 | 役割 |
| --- | --- |
| `要は` | 本当の目的へ絞る |
| `あくまで` | 範囲や前提を限定する |
| `なので` | 根拠から依頼や判断へ進む |
| `ただ` | 採用方向を残したまま制約を置く |
| `そもそも` | 前提自体を問い直す |
| `故に` | 技術的な因果を短くつなぐ。多用しない |

`要は`で同じ結論を言い直すだけなら削る。
接続詞がなくても順序で読める場合は置かない。

## 語尾

### チャット、依頼

- `〜できる？`
- `〜して欲しい`
- `〜だと思う`
- `〜でいいよね`
- `〜かな`
- `〜なんだよね`
- `〜がベスト`
- `〜でいこう`

近さは語尾で出す。
本文全体を雑にしない。

### レビューの語尾

- `〜はNG`
- `〜だと弱い`
- `〜でいいと思う`
- `〜したい`
- `〜では？`
- `具体的に何を指す？`

否定で終わらず、理由か修正方向を続ける。

### 技術文書

- `〜する`
- `〜にする`
- `〜は対象外`
- `〜まで確認した`
- `〜は未確認`

`だ`、`である`を機械的に並べない。
動詞で言い切る文を混ぜる。

## 語彙

技術用語、コード識別子、チーム内で定着した英語はそのまま使う。
`PR`、`CI`、`v1`、`YAGNI`、`source of truth`のように、短く正確な語を無理に翻訳しない。

一方、雰囲気を作るだけの英語は足さない。
本人が使っていない横文字で文章を飾らない。

## 温度の調整

率直さは高め、演出は低め。
相手ではなく、前提、設計、事実へ指摘を向ける。

疑問形は断定を避けるためではなく、認識や前提を揃えるために使う。
不確実な内容は曖昧にせず、未確認の範囲を具体的に示す。

チャットでは`よね`、`かな`、少し伸ばした語尾が入ることがある。
これは親しさの温度であり、あらゆる文章へ移す癖ではない。

## 再現しないもの

- 誤字や変換ミス
- 入力途中の語順
- `、、？`のような句読点
- 参照用の`↑`
- 伸ばし棒の頻度
- 一度だけ現れた言い回し

表面の癖ではなく、その下にある呼吸を再現する。

## profileの更新方法

本人が出力を書き直した場合は、単語だけでなく次を比較する。

1. どの文を分割または結合したか
2. どこへ空行を入れたか
3. 語尾をどの強さへ変えたか
4. 接続詞を足したか、削ったか
5. 温度を上げたか、下げたか

一回の修正を規則にしない。
複数回繰り返した傾向だけをprofileへ昇格させる。
